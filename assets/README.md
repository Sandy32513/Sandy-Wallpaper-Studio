# Sandy Wallpaper Studio — Project Assets

This directory stores project-level static assets used for application branding, documentation, and Windows desktop packaging.

## Structure and Asset Types

- **`icons/`**: Application icons formatted for Windows (`.ico`) with multi-resolution layers (16x16, 32x32, 48x48, 64x64, 128x128, 256x256), and high-resolution PNG masters.
- **`branding/`**: Logo vector sources, wordmarks, and dark-theme badge assets.
- **`packaging/`**: Installer banners, header art, and license display templates used by the Windows Installer builder in Phase 13.
- **`screenshots/`**: High-resolution interface captures featured in project documentation and releases.

## Asset Policies

- All assets must be free from proprietary licensing encumbrances.
- Do not commit large wallpaper collections or user image libraries to this directory.
