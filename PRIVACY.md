# Privacy Policy — Sandy Wallpaper Studio

**Version**: 1.0.0
**Last updated**: 2026-10-02

---

## Summary

Sandy Wallpaper Studio is a **fully offline-capable desktop application**.
It does **not** collect, store, or transmit any personal data.

---

## Data Collection

| Category | Collected? |
|---|---|
| Personal information | ❌ No |
| Usage analytics | ❌ No |
| Crash reports | ❌ No |
| Telemetry | ❌ No |
| Advertising identifiers | ❌ No |

---

## Network Requests

Network requests are made **only** to the wallpaper source providers you have
enabled in Settings (e.g., Wikimedia Commons API). These requests are used
exclusively to search for and download wallpaper images.

No local files, library metadata, or personal information is ever uploaded.

---

## Local Data

The application stores the following **locally on your computer**:

- Downloaded wallpaper images (in your chosen library folder)
- Wallpaper metadata (title, author, license, resolution) in a local SQLite database
- Application settings in a JSON file
- Application logs (rotated automatically, stored in the Logs directory)
- Thumbnail cache (in the Cache directory)

All local data stays on your machine and is never transmitted.

---

## Third-Party Services

| Service | Purpose | Data Sent |
|---|---|---|
| Wikimedia Commons API | Search & download free wallpapers | Search query text only |

No API keys containing personal information are used.

---

## Your Control

- You can delete your entire library at any time.
- You can clear the cache from Settings.
- You can disable any wallpaper source.
- Uninstalling the application does not leave hidden files behind
  (other than your wallpaper library, which you manage yourself).

---

## Contact

If you have questions about this privacy policy, please open an issue
in the project repository.
